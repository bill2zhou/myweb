      ▶说明解析规则 / 跨域限制 / Everything 字段
      查询逻辑与 WinForms 版一致 —— SN 以 _ 分割取第一段，长度大于 10 才请求接口； 接口返回内容按 SET SKU=、SET MODELNAME=、SET SN=、SET SNMULTI=、 SET SSNMULTI=、SET SNMACMULTI=、SET GROUPMULTI= 等规则解析，输出 model、sku、站点及各板卡 SN_PPID_MAC。
      跨域限制：浏览器只允许页面请求同源地址，协议 + 主机 + 端口 任意一项不同都算跨域。 页面若放在 http://192.188.0.240，则 http://192.188.0.13:9092（主机不同）会被拦截， http://192.188.0.240:2016（端口不同）视服务端响应而定。当前采用的做法：
      ① FMDI 查询走同源转发（两种做法任选其一）：
          a) 运行 web-proxy 里的同源转发服务：测试资料查询代理.exe（免装运行环境，双击即跑） 或 proxy.js（Node）——它同时托管页面并转发接口， 改用 http://<该机器IP>:8080/ 打开页面，接口地址填 /fmdi、Everything 地址填 /everything；
          b) 把本页直接放到接口所在站点（192.188.0.13:9092）目录下，接口地址改用直连，同样同源；
      ② Everything 也走同源转发：地址填 /everything（转发服务会代加 engineer 的 Basic 认证）， 经 http(s) 打开页面时默认就是该地址——Everything 的 HTTP 服务不返回 CORS 响应头， 直连 http://192.188.0.240:2016 必被浏览器拦截；
      Everything 搜索：每次查询成功后，自动取回传里的前两个 PPID，分别调用 Everything HTTP 服务（默认 http://192.188.0.240:2016，账号 engineer） 搜索并显示在两个并排窗口里，每条结果显示文件名、完整路径、大小与修改时间。
      文件预览：点击条目弹出窗口显示文件内容 —— .txt 按文本显示（UTF-8 优先，非 UTF-8 自动按 GBK/GB18030 解码）， .webp 等图片按图片显示（打开时居中，按原始像素渲染，清晰度与看图软件一致），支持滚轮缩放（以光标为中心）、左键按住拖动平移、 「旋转」每次顺时针 90°、「还原」恢复适应窗口大小/角度/位置（也可双击图片还原）； 弹窗内可「复制路径」或「新窗口打开」，按 Esc 或点遮罩关闭。 浏览器不能直接读 D:\…、H:\… 或 \\共享\… 这类路径，所以内容由服务端读取： Everything 设置里的「文件预览地址」填 /file，由站点的 server/routes/preview.js（或独立运行时的 web-proxy/proxy.js） 提供 /file?path=完整路径 接口。服务所在机器必须能访问这些路径（映射盘、共享都要有权限）， 否则会提示「文件不存在或无权访问」；旧版服务/代理不含该接口时，需重新打包。 大小字段兼容 size / file_size / length 等命名及数字、数字字符串、可读文本三种类型； 若显示为「大小 —」，状态行会给出服务端实际返回的字段名，悬停条目可看到原始 JSON。
